# Aqualina Marbella & Ibiza — React (Vite)

Luxury real-estate website inspired by [aqualinamarbella.com](https://www.aqualinamarbella.com/), rebuilt in React + Vite.

## Run

```bash
npm install
npm run dev
```

## Pages

- Home — hero, categories, apartments, villas, branded residences, team, contact, testimonials
- Marbella — full apartment & villa listings
- Ibiza — Balearic highlights
- Property Management
- About Us
- Contact

Listing prices/locations mirror publicly shown Costa del Sol inventory for demo purposes.
